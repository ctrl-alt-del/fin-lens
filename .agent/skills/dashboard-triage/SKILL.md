# dashboard-triage — 看盘与异常判定

## 何时用

- 用户问"今天怎么样 / 有没有异常 / 哪只跌得最狠 / 有没有重叠"。
- 开盘后、午盘、收盘前快速巡检。
- 盘后验证之前，先确认当天的盘中估算与告警状态。

## 不该用

- 用户问"估得准不准" → 用 `daily-validation`。
- 数据时点明显过期 → 先 `market-refresh`，再回来 triage。

## 步骤（只读，不改库）

```bash
# 页面：人类看
open http://127.0.0.1:8787/

# 机器看：
curl -s http://127.0.0.1:8787/api/estimates   # 全部基金估算；单只用 /api/funds/{code}/estimate
curl -s http://127.0.0.1:8787/api/lookthrough | jq '{weights_assumed_equal, alert_count: (.report.alerts|length), top: .report.exposures[:5]|map({name,total_weight,fund_count})}'
curl -s http://127.0.0.1:8787/api/funds | jq 'length'
```

无服务时：`FINLENS_DB=data/finlens.db FINLENS_BIND=127.0.0.1:8787 ./target/debug/fin-lens &`

## 判读顺序（页面 ①→④）

0. **先读顶部「一句话」**：它已经把 1 年超额、最大贡献桶、最大拖累桶和口径限制压成一句。
1. **①今天 / Hero 数据时点**：`快照 15:32` 是否在 15 分钟内；盘后 A 股已收市，快照停在 15:0x 属正常，
   但结论必须带时点。区间 chips 看的是「当前份额回溯」，不是账户真实收益。
2. **今日估损**：从页面 Hero 读总市值、今日 ±¥ / ±% 与覆盖率；不要记忆上一轮基线。
3. **②风险 / 体检五信号**（左列）：资源集中度、穿透集中度、近一年回撤、波动率、数据完整性。
   红/黄/绿是规则输出，不是模型打分；具体数值从页面或 `/partials/overview` 读取。
4. **Action items**：先看红条。条数与文案由页面实时生成；它们是核对/补数据动作，不是买卖建议。
5. **资源桶 donut**：从页面读取桶权重；「黄金+有色」是另一条美元/实际利率逻辑，
   不能混算成"行业分散"。
6. **穿透 Top 8**：从 `/api/lookthrough` 的 `report.exposures` 读取；单票阈值 5%。
   覆盖不足时明确写「下限」。
7. **③是不是真的跑赢 + 归因**：从页面 ③ 读取组合/基准/桶贡献；跨资产比较只作参照，
   不要把黄金涨/跌说成选股能力。穿透篮子的收益不可交易，只作暴露解释。
8. **④要盯的基金**：按原因数量排序；覆盖不足 + 今日大跌的优先核对，不要把它们的估算当准数。

## 输出模板（三条以内）

1. 组合：`今日估算 <±%>（<±¥>），最深 <A> <a>%、<B> <b>%；快照 <time>。`
2. 暴露：`黄金+有色 <w>%（<红/黄/绿>），穿透第一 <name> <w>%（<n> 只），覆盖仅 <cov>%（下限）。`
3. 待办：`先补 <n> 只基金市值；成本已知仅 <n> 只，累计浮亏不代表总账户。`

## One-pager 与 Reference

- 首屏只放结论；基金卡片、穿透全表、口径说明都折叠在页面底部 `Reference`，
  需要逐只核对时再展开。
- 页面每 30s 用 `/partials/overview` 局部刷新（轮询，不是 SSE）；刷新只换数字，不换口径。
- 如果页面数字与 `/api/funds` 不一致，先看 `quote_ts`，再看是否跨了刷新周期——不要手工改库。

## 失败处理

- **/api/lookthrough 的 exposures 为空**：`holding` 或 `position` 没数据 → 先 `market-refresh` 或检查 seed。
- **页面 200 但数字全 0**：`quote_snapshot` 为空（非交易时段），不是 bug；说明数据时点即可。
- **同一只基金两次刷新差异大**：盘中价在动，属正常；不要缓存旧结论。

## 不要做

- 不要把等权估算说成"你的组合收益"。
- 不要在没看 `flags` 的情况下把低覆盖基金的数字当精确值。
- 不要为了"回答更满"去猜持仓变动——季报口径有滞后，猜错比不说更糟。

## QDII 看盘注意

- `category=qdii_index` 的基金，卡片上会显示 `美股T-1` 标记与「美股T-1 −x% · 汇率 ±y% · β」明细。
- 它反映的是**上一夜美股收盘** + USD/CNY 变动，不是 A 股时段的实时联动；不要拿盘中 A 股涨跌去解释它。
- 若标的显示 `缺汇率`，说明 `FX.USDCNH` 快照缺失，先跑 market-refresh。
